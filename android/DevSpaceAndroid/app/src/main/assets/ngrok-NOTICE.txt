ngrok Agent SDK notice
======================

DevSpace Mobile embeds a small Android-native forwarding runtime built from
the official ngrok Go Agent SDK. It does not bundle or execute the upstream
Linux ngrok CLI binary.

Component: golang.ngrok.com/ngrok/v2
Version: 2.1.4

The runtime is compiled for GOOS=android, GOARCH=arm64 and communicates with

usage remain subject to ngrok's service terms and the user's ngrok account.
