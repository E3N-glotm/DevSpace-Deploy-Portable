# DevSpace Portable 1.1.10

## 修复范围

1.1.10 延续 1.1.9 的单一原生 Windows x64 控制中心，集中修复真实桌面截图中暴露的视觉残块、配置页裁切和 Computer Use 开关耦合问题。协议保持 1.5，不新增、删除或修改顶层 MCP 工具。

## 原生界面

- 圆角按钮、开关、分组框和玻璃面板在自绘前先解析不透明父背景并清空画布，消除透明区域未初始化造成的黑色四角和黑边；
- 配置页改为自动首选高度加页面级纵向滚动，公网、本地端口、权限、功能、Owner Password 与保存/部署操作均可到达；
- 插件页降低上半区默认高度，为 16 个预留槽位提供更充足的可视区域；
- 会话页保持列表、文件详情和差异三块结构，未选择文件时显示明确提示；
- 日志页保留两块独立长文本区域，可在服务持续写日志时刷新读取；
- 五个页面已在真实 Windows 桌面逐页检查，结构自检包含 5 个页面和 40 个按钮。

## Computer Use 与运行时韧性

- 顶栏开关改用独立的 `set-computer-use` 管理命令，不再要求先填写公网域名或 Tunnel Token；
- 关闭后立即停止当前 Portable 的 Broker 并移除状态文件，开启时仅在权限允许且 UI 租约有效时启动；
- 心跳发现租约文件丢失或租约 ID 变化时自动取得新租约；
- 相同 Portable 根目录的第二个原生进程直接退出，不会新建或替换首实例租约；
- UI 租约有效期为 90 秒，首次本地服务启动等待由 20 秒提高到 120 秒；
- 服务和隧道通过共享追加启动器写日志，原生读取端允许 `ReadWrite` 与 `Delete` 共享。
- WGC、DXGI 返回的 BGRA 帧在编码前检查有效可见像素；锁屏、休眠、受保护桌面或错误 Window Station 产生的全透明/近空帧不再被误报为成功，而是继续尝试后备后端或返回明确失败。

## 验收

- 新增自动回归覆盖租约删除恢复、关闭 Computer Use 不启动 Broker、日志持有追加句柄时可读、第二实例不创建新租约；
- 运行卡片、运行日志、插件管理、Codex Runtime Bridge、会话回退、Computer Use Broker、原生 UI 和严格停止回归通过；
- 实机开关复测确认关闭后旧 Broker 消失，重新开启后新 Broker 状态为 `running` 且租约匹配；
- Explorer Shell 启动的真实用户桌面连续 5/5 次 WGC 捕获成功，分辨率 3840×2160，平均端到端约 395 ms；重新编译后的截图 Helper SHA-256 为 `66a3eaf5104c0c4f8919f13a9172a46de0552d759e31e075645abbe1b23b0af6`；
- 构建与测试仅作用于 `E:\program\Python\DevSpaceDeploy`，未覆盖、停止或迁移 `D:\DevSpacePortable` 正式部署。
