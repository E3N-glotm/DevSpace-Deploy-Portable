# DevSpace Portable 1.1.14

1.1.14 重构原生控制中心的操作反馈、会话审阅和显式 Memories 管理，Portable Protocol 保持 1.5，现有 MCP 顶层工具定义不变。

## 操作期间不再整窗变白

- 原生 UI 不再通过禁用整个 `MainForm` 表示操作进行中，避免 WinForms 把所有卡片、表格和控制框绘制成白色或失焦状态。
- 只有当前点击的按钮进入忙碌状态，并在按钮内部显示“执行中…”。
- 页面内容、日志和其他导航保持可见；重复点击同一忙碌按钮会被忽略，操作结束后恢复原文字和光标。
- 初始化阶段同样不再禁用整窗，而是在状态框中显示加载进度。

## Codex 风格会话子页面

- “会话与回退”首先显示独立会话列表，而不是把列表、文件和差异压缩在同一个三栏页面中。
- 双击会话或点击“查看本轮修改”进入会话详情子页面，可通过“返回会话”回到列表。
- 详情页集中显示本轮项目路径、稀疏审阅后端、文件数、增删行数和完整回退状态。
- 改动文件以独立列表呈现；选择文件后只显示该文件对应的 patch，并使用不同文字颜色区分新增、删除、区块和文件头。
- 回退、恢复回退前快照和打开项目目录均保留在详情页，不改变 `sparse-journal-v4` 的有界存储和安全回退规则。

## 显式 Memories 独立页面

- 左侧导航新增“显式 Memories”页面，可搜索和查看本地 SQLite 中的全局与工作区记录。
- 支持新建、编辑、保存和删除；工作区作用域只能选择当前配置中的 `allowedRoots`，不能通过 UI 写入任意外部路径。
- 支持标题、内容和逗号分隔标签；全局作用域不绑定项目，工作区作用域明确显示对应根目录。
- 删除前要求确认，疑似密码、Token、API Key 或 Client Secret 的内容继续由 `MemoryStore` 拒绝。
- Memories 仍然只由用户或模型显式写入，不会从聊天、命令输出、文件内容或浏览历史自动推断。

## 自动回归

- 原生 WinForms 编译通过。
- 新增 `setup/test-portable-ui-workflows.mjs`，验证整窗不再被禁用、会话子页面存在，以及 Memory 的创建、读取、更新和删除均通过真实 SQLite 完成。
- 原生 UI 韧性测试与 `sparse-journal-v4` 会话能力回归继续通过。
