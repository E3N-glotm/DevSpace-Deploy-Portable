# DevSpace Portable 1.1.68 dev3 — 选中模型调用统计

本版在桌面本体的“模型提供商”中增加当前选中模型的调用统计。
新增逻辑位于原有 DevSpace Portable 本体，不依赖插件，也不更改
现有 ChatGPT MCP 工具授权、远程 Agent 身份或本地模型 API 配置。

## 统计指标

- 最近一次调用开始时间、最近一次请求耗时及成功／失败状态。
- 累计 API 调用次数、成功次数、失败次数、输入 Token、输出 Token
  以及总 Token。
- 累计 HTTP 请求耗时、按已配置单价计算的 USD 估算费用。
- 将 MCP Worker 的逐轮推理、桌面“测试连接”和“Function Calling 检测”
  分开统计；没有返回 usage 字段的请求单独计数，避免虚报 Token。
- 选中模型后自动加载并每 10 秒刷新一次；支持手动刷新。

## 计数口径和保存方式

- **统计单位是一次实际推理 API 请求，不是一次 ChatGPT 对话**。
  一个 Worker 任务发生多轮模型调用时，会记录多次。
  工作区读文件、目录浏览、Git 命令和“获取模型列表”不计入推理次数。
- 根据模型配置 ID 与真实模型标识分开统计；同一服务器的 32K／128K／
  256K 不混算，模型配置换成其他模型后不会显示旧模型的累计次数。
- 从 dev3 启用后开始累计；无法凭空还原 dev2 以前的历史推理调用。
  WebUI 或其他客户端绕开 DevSpace 直接请求模型服务的调用**不在此统计中**。
- 统计数据保存在 Portable 用户数据目录的
  `data/state/model-usage-v1/` 下，按月份分目录、每次请求单独原子写入，
  Electron 和 MCP 服务端并行写入不会覆盖同一计数文件，重启后保持统计。
- 不保存提示词、回答正文、工具调用参数、API Key、Authorization
  请求头或实际 API URL。不存在或无法读取的 Token 使用量不予估算。

## 已知限制

- 费用由用户自行填写的模型单价和 API 返回的 usage 估算，不能代替
  云端供应商账单，也不能作为预算硬限制。
- 目前没有将本机 Open WebUI 独立的 OAuth 续期逻辑并入 DevSpace：
  Open WebUI 的 Access Token 到期处理属于另一个程序，须在其源码内
  独立修复，不能通过放宽 DevSpace MCP 的身份校验来规避。
- 原始统计事件文件会随调用数增长，后续可引入归档／聚合策略，
  但不得在未保留累计总数前直接丢弃历史记录。
