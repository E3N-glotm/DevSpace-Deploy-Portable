# DevSpace Portable 1.1.68 dev15 — Agent 协作动态与推理适配

- Agent 工作台默认汇总协作动态，不再要求先选择任务；手动启动任务移入可选弹窗。任务控制、成员状态、实际模型输出、工具与审查证据仍保留。
- 模型提供商增加创建／管理模型组入口，组管理移入独立弹窗。模型名称显示上下文容量，成员显示唯一配置 ID；配置的上下文容量与服务声明不一致时提示。
- 思考程度默认按已知协议自动适配，Qwen Flash Next 原生预算、DeepSeek 与 OpenAI 兼容格式分别映射。高级手动适配可选。真实探测显示正式任务映射、短探测实际发送参数、HTTP 接受状态与返回的思考证据；不把参数被接受或思考文本存在当作精确档位已证实。
- 保留既有独立审查门槛，并确保每位组员至少实际执行一次推理后才允许自动完成；默认仍为轮转式调度和单写入者。
- 请求流模式明确请求用量；若供应商不报告推理 Token，界面显示未报告。

现有模型配置、模型组、任务库、OAuth、API 凭据与运行目录不需要迁移。旧 native 适配值仍兼容自动解析；未知思考协议显示不支持，不推测有效档位。旧 Worker 接口保持显式选择；上游若使用默认组，调用 agent_task_start，旧客户端缓存的工具 schema 需刷新。
