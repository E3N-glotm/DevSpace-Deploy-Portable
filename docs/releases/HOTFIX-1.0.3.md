# 1.0.3 多语言 Windows ACL 热修复

旧版把 `whoami` 返回的本地化账户名按 UTF-8 解码后交给 `icacls`。当计算机名或用户名包含
中文、日文等字符时，账户名可能损坏，Windows 随后报告“账户名与安全标识符之间无映射”。

1.0.3 改为使用当前登录用户的 Windows SID 授权，因此不再依赖用户名、计算机名或显示语言。
同时，启动服务前会检查两个计划任务是否已经安装并给出明确提示。

已发生该错误的电脑无需删除 `data`：

1. 停止旧版菜单；
2. 把 1.0.3 热修复包解压到便携目录的上级目录并覆盖同名文件；
3. 重新打开 `DevSpace-Portable.cmd`；
4. 保留原有 Token/Owner Password 输入框为空，重新点击“保存并自动部署”；
5. 确认状态显示两个任务已安装，随后执行完整端点测试。

热修复包不包含 `data`、`logs` 或 `reports`，不会覆盖现有凭据及 OAuth SQLite。
