# DevSpace Portable 1.1.68 正式版

适用于 Windows x64。此版本将 1.1.68 dev33 提升为正式版。

## 同版本修订（2026-11-19）

- 修复 Agent 协作流程窄列卡片中长标题、工具名称和箭头超出边框的问题；标题在卡片内省略显示，悬停可看完整标题，点击仍可查看完整记录。
- 改善详情弹窗中连续长文本的换行。版本号保持 1.1.68，完整包、blockmap 和更新校验信息同步重新生成。

## 模型提供商和 Agent 工作台

- 支持管理多个模型提供商、保存模型组和分配成员角色。全局调度支持自动、单模型和模型组，可供 MCP 委派和桌面任务使用。
- Agent 工作台保存协作过程、工具记录和执行结果。模型统计支持清空。GPT 委派的单模型任务交付后可自动归档，要求独立复核的任务仍按复核流程处理。
- MCP 委派继承 DevSpace 全局授权，上游可以明确限制单项权限。工作区访问仍受已配置的目录范围约束。任务控制按对话隔离，取消操作记录来源。
- 修复长任务压缩后因消息顺序被 Qwen 拒绝而报 503 的问题。恢复旧任务时会修正已保存的消息顺序。改进模型持续输出时的滚动位置，以及推理等待和大回复的处理。

## 桌面操作和远程连接

- 改善 Computer Use 点击坐标和操作后截图时机。支持直接读取浏览器页面结构，减少通过截图识别元素的需要。
- 改善远程 Agent 多网卡连接、SSH 反向隧道和断线恢复。自动续轮可独立开关。

## 依赖

- 更新 Hono 至 4.13.19，fast-xml-parser 至 5.12.0。

## 更新

GitHub Release 提供完整 ZIP、`.blockmap`、增量更新包和 SHA-256 校验清单。已安装版本可通过 DevSpace 自带的更新入口升级。升级流程保留配置、任务数据和已登记的 Agent。
