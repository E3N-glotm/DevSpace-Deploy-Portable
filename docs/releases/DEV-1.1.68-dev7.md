# DevSpace Portable 1.1.68 dev7 — Worker 授权、长任务与公网恢复

## 强制 Worker 的 MCP 授权

- 同一服务实例的 Worker 运行时通过 WeakMap 共享授权，避免 MCP transport 重建后失去授权；仍严格按会话作用域、工作区、策略版本和模型配置隔离。
- 通过 AsyncLocalStorage 将 HTTP 工具调用的 openai/session 一致传入 Worker 委派、结果处理与请求门禁；无显式会话元数据时，仅回退到已认证的 MCP session ID，不跨不同会话借用授权。
- 继续保留 GPT 并行只读、同工作区单写入者、模型结果审查、远程 Agent 工作区豁免本地强制 Worker 的规则。
- 强制模式下无需事先委派就允许执行不修改状态的只读诊断，包括 plugin_list、process_list、audit_log_list 等；文件修改与 Shell 操作仍受门禁限制。

## 长任务

- maxSteps 可配置 1 至 100000，默认 1000；timeoutSeconds 可配置 30 至 86400，默认 3600。
- 工具调用额度随任务步数扩大，不再固定 24 次；保留手动取消、时间与费用预算、模型启用状态、文件权限与工作区互斥。
- 长对话保留原始用户目标和近期完整工具调用，压缩旧工具历史；内部证据最多保留 100 条，外部结果返回最近 25 条，避免无界内存增长。
- 测试验证 Worker 连续执行 80 步／80 次工具调用后完成，并通过 OAuth/MCP 对高步数和长超时进行参数验证。

## Cloudflare 公网 MCP 恢复

- 现有 ngrok 恢复仍要求确认自身 agent 缺少目标隧道，不因单次公网失败重启。
- Cloudflared 活着但公网 MCP 持续不可达时，原逻辑不会主动重连。新增自有子进程保守恢复条件：本地 MCP 返回预期 401、网络路径可用、连续至少 12 次（约 3 分钟）公网连接失败或超时，且子进程确实归当前 supervisor 所有。
- 重启仅针对 DevSpace 自己的 cloudflared 子进程；DNS、TLS、本地 MCP 故障、无可用网络路径或偶发超时不会触发重启。冷却时间递增至最多 30 分钟，恢复健康后重置。
- 仍不能断言用户先前超过 100 分钟的连接中断全部源于本地 Cloudflare；OpenAI 连接器端故障及第三方服务中断不受此逻辑控制。本版覆盖已观察到的公网超时且恢复条件永不满足的缺陷。
- 不改变任何 55801/55301 远端训练、模型路由、SSH、网络配置或操作系统代理。

## 验收与发布边界

- 门禁单元测试、Worker 运行时、真实隔离 OAuth/MCP、隧道自检、完整源码回归及 ZIP CRC 分别验收。
- E 盘源码为唯一开发工作区；D 盘正式 Portable 未经另外确认不得覆盖，生成 dev7 ZIP 不等于已部署。
