# DevSpace Portable 1.1.70 dev1

## 蓝屏后的启动恢复与远程连接容错

- 对明确列入白名单的临时运行状态 JSON，读取失败时保留损坏原始字节，以内容哈希去重备份，并按未初始化状态处理；不重置真实配置或认证数据。
- Agent-only LAN 网关与本地 MCP 解耦。已配置监听端点暂时不可绑定时保留正常端点，并每五秒尝试恢复，不隐式扩大对外监听范围。SSH 回连改为转发到本机 Agent-only loopback，不再依赖原网卡地址。
- SSH 回连监督器在 MCP CLI 启动时恢复；独占所有权避免同一配置重复运行 SSH 子进程。手动连接恢复时，确认离线 Agent 且旧端口仍被占用后，通过 SSH 验证新端口，仅接受 loopback 监听及可访问的 Agent 入口。
- SSH 端口切换失败恢复原有隧道配置，远程 Agent 继续使用已有身份和目录授权。未授权网卡、新网络路由和主机身份变更仍需用户明确配置；不自动重装或关闭其他进程。
